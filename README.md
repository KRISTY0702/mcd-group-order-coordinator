# mcd-group-order-coordinator
麦友多人点餐协调员是一个基于麦当劳官方 MCP（mcd-mcp）开发的 WorkBuddy Skill，帮一位发起人把多人各说一句「想吃什么」整理成可确认、可分摊、可下单的订单方案：补齐就餐方式、地点、人数与每人偏好忌口，生成可转发群聊的征集模板，查询门店与实时菜单，按官方团餐档位为每人生成候选餐品，识别忌口过敏、售罄与优惠券不可用，调用 calculate-price 试算真实总价并算出每人分摊，仅在发起人明确回复「确认下单」后才创建订单。三条硬约束：不自动领券、未获确认绝不创建订单、对过敏与严重忌口只做排除与醒目风险提示、不声称餐品绝对安全；所有门店、餐品、价格与优惠均来自 MCP 实时返回，拿不到即报错并提示应调用的工具，绝不编造。
